# London Underground: Is the Difference Real, and Does It Matter?

Where should a pilot air-cooling system go first? Data cleaning, temperature distributions by line, and t-tests comparing the two hottest lines (Bakerloo vs Central) across the whole year and in summer only, including effect sizes.

- **Full analysis (report):** [underground-analysis.md](underground-analysis.md)
- **Source code (R Markdown):** [underground-analysis.Rmd](underground-analysis.Rmd)
- **Article (Spanish):** [La diferencia era real. Pero, en la práctica, irrelevante](LINK-SUBSTACK)

*Data based on the [London Underground Average Monthly Temperatures](https://data.london.gov.uk/dataset/london-underground-average-monthly-temperatures-epr8d) published by Transport for London. The analysis uses a version prepared for a master's course assignment, which is not included in this repository.*
